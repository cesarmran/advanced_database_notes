## What I understood
- UNION is used to combine the results of two SELECT queries.
- UNION removes duplicate rows, so the result only shows unique values.
- INTERSECT returns the rows that appear in both queries.
- MINUS (or EXCEPT in some databases) returns the rows that exist in the first query but not in the second one.
- These operators help compare data between tables and combine query results.
