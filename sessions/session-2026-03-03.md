## What I understood
- ORDER BY is used to sort the result set based on one or more columns
- PARTITION BY divides the data into logical groups inside analytic functions without reducing the number of rows
- Analytic functions allow calculations like ranking, running totals, and averages while still showing all rows
- Sliding windows define a range of rows around the current row to calculate things like cumulative sums or moving averages
