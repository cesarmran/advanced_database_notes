## What I understood
- A database backup is a copy of the database (or schema) that allows us to recover data if something goes wrong.
- The schema includes the structure of the database, like tables, columns, and relationships.
- Backups are important to prevent data loss in cases like system crashes, errors, or accidental deletions.
- There are different types of backups. A full backup saves everything, while incremental backups only save changes.
- The restore process is used to recover the database from a backup file and bring it back to a previous state.
- I understood that backup and restore are key parts of database management and should be done regularly.
