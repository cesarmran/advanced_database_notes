## Topics covered
- Aggregate functions in SQL (COUNT, SUM, AVG, MIN, MAX)
- GROUP BY
- HAVING clause
- Filtering aggregated results
- Basic data analysis using SQL

## What I understood
- Aggregate functions help summarize data instead of showing every single row
- COUNT is useful to know how many records exist, SUM adds values, AVG calculates averages, and MIN and MAX help find extreme values
- GROUP BY lets us divide data into groups so we can analyze each group separately
- HAVING is used to filter grouped results, while WHERE filters rows before grouping
