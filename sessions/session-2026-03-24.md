## What I understood
- A trigger is something that runs automatically when an action happens in a table.
- BEFORE INSERT triggers can be used to fill data automatically, like date and user.
- BEFORE UPDATE triggers can control who is allowed to change a record.
- BEFORE DELETE triggers can restrict who can delete data.
- :NEW is used for the new values and :OLD for the previous values.
- USER gives the current user and SYSDATE gives the current date.
