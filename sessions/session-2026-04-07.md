## What I understood
- An index is a structure that helps the database find data faster, without checking every row one by one.
- It works in a similar way to an index in a book, because it helps locate information more quickly.
- Indexes are very useful when a table has many records and we often search by the same columns.
- A primary key usually has an index, and this helps keep values organized and easy to find.
- Indexes improve `SELECT` queries, especially when we use conditions like `WHERE`, joins, or sorting.
- I also understood that indexes are helpful, but they are not always free, because they also need space and maintenance.
