## What I understood
- Vector search helps find information based on meaning, not only exact keywords.  
- Text can be transformed into embeddings, which are numerical vectors.  
- Similar pieces of text have vectors that are closer to each other.  
- Semantic search uses these vectors to return results that are related in meaning to the question.  
- This makes search more flexible, because it can still find useful results even when the same words are not used.
