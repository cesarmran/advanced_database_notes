## What I understood
- A procedure is a stored block of code that can execute tasks inside the database, which helps avoid repeating the same SQL instructions many times.  
- Procedures can include logic, conditions, and multiple operations, which makes them useful for automating processes.  
- I understood that procedures can be used for things like inserting, updating, or validating data.  
- A transaction is a group of operations that the database treats as one unit of work.  
- COMMIT saves the changes made during a transaction, while ROLLBACK cancels them if something goes wrong.  
- Transactions help maintain consistency in the database and avoid leaving incomplete changes.  
- I also understood that procedures and transactions can work together, for example, using a procedure that performs several operations inside a transaction.
