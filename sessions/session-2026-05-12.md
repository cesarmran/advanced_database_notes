## What I understood
- A database migration is used to control and apply changes to the database structure over time.
- SQLAlchemy ORM allows us to work with database tables as Python classes instead of writing only raw SQL.
- Alembic helps generate and apply migrations when the database schema changes.
- The `upgrade()` function applies the new changes to the database, such as creating a new table or adding a column.
- The `downgrade()` function reverses a migration, which can remove a table or undo a schema change.
- I understood that migrations are useful because they keep the database changes organized and easier to track.
- Relationships are important because they connect tables, for example, comments can belong to a task and also to a user.
- Rollbacks are useful when a migration was incorrect or added something that should not be in the database.
