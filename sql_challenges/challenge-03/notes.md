Today I learned how to use aggregate functions in SQL to summarize data instead of just selecting rows, I understood how functions like COUNT, SUM, AVG, MIN and MAX help to analyze information inside a table, for example counting how many records exist or calculating the average value of a column, I also learned how GROUP BY allows us to group rows that share the same value so we can apply aggregates to each group, and how HAVING is different from WHERE because HAVING filters after grouping, not before, overall I understood that aggregation is very useful when we want insights and not just raw data.
