Today we learned about indexes in databases, and how they help queries run faster by avoiding full table scans, they work like an index in a book, helping find data quickly, I understood that indexes are very useful when we search by columns with many different values, like patient_id or email, but not so useful for columns with few values, like status or site_id, I also learned that indexes are better for queries that return small parts of the table, and that things like functions or wrong column order in composite indexes can stop Oracle from using them, I still need more practice to understand when exactly to create an index and how to choose the best columns in real scenarios.
